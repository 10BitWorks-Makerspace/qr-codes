# 10BitWorks QR Generator

## Project Constraints
- Must be a single page webapp.
- Must generate QR codes with SVG output.
- Must use the custom design for the QR code (isometric cube in a hexagon for the 3 finder patterns).
- Use HTML/JS (Vite vanilla-ts template).
- Do not use TailwindCSS. Use Vanilla CSS for styling.
- Design must feel premium, modern, dynamic, and responsive (glassmorphism, vibrant palettes, micro-animations).
